# Bektemur Bektemurov — Portfolio

Frontend dasturchi Bektemur Bektemurov uchun oddiy, bir sahifali landing page.

🔗 **Jonli sayt:** [bektemur.nurlihost.uz](https://bektemur.nurlihost.uz)

## Texnologiyalar

Sof statik sayt — hech qanday build yoki backend talab qilmaydi:

- **HTML5** — semantik razmetka
- **CSS3** — dark theme, responsive layout, CSS grid/flexbox, animatsiyalar
- **Vanilla JavaScript** — mobil menyu, scroll animatsiyalari (IntersectionObserver), skill-barlar

## Tuzilishi

```
.
├── index.html          # Asosiy sahifa
└── assets/
    ├── style.css       # Barcha uslublar
    └── script.js       # Interaktivlik
```

## Bo'limlar

- **Hero** — tanishtiruv
- **Men haqimda** — qisqa ma'lumot
- **Ko'nikmalar** — HTML, CSS, JavaScript, React + Matematika, Ingliz tili
- **Sertifikat** — CERL frontend sertifikati
- **Bog'lanish** — kontakt ma'lumotlari

## Lokal ishga tushirish

Oddiygina `index.html` faylni brauzerda oching yoki statik server bilan:

```bash
python3 -m http.server 8080
# http://localhost:8080
```
